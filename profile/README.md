### What we’re building

Niu aims to give teams one place to connect model providers, route AI requests, understand usage and cost, and enforce access policies. Our direction is a self-hosted gateway and management platform with a Rust runtime and a practical operator experience.

- **Performance you can measure.** Track latency, time to first token, throughput, and reliability across the request path.
- **Cost you can explain.** Make provider pricing, usage, and the cost of each attempt attributable and understandable.
- **Security at the foundation.** Keep provider credentials server-side and preserve tenant authorization and data boundaries.

### Built in the open

Niu is in early development. The public repository is the source of truth for what is available today; architecture documents describe the direction, including capabilities still to be implemented. Start with the [project README](https://github.com/niu-io/niu#current-status) for implementation status.

We selectively reuse small, independently licensed components from the open-source ecosystem, including LiteLLM, and preserve their provenance and licenses. See our [third-party notices](https://github.com/niu-io/niu/blob/main/THIRD-PARTY-NOTICES.md).
